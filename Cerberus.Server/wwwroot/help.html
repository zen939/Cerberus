Cerberus 功能說明

← 返回管理後台

系統概觀

Cerberus 是企業端點防禦與監控系統，用來阻擋並監控未授權的遠端控制軟體（AnyDesk、TeamViewer、RustDesk、向日葵等）與內網穿透工具，並回報威脅與異常登入。架構為：

  • Agent（端點，SYSTEM 服務）：偵測、處置、回報，並接受 Server 的白名單指令。
  • Tray（系統匣）：氣泡通知、狀態顯示。
  • Server（本後台）：接收心跳/告警、失聯偵測、Webhook 轉發、下達指令。

處置模式（Mode）

模式行為適用
Audit偵測到只告警、不處置。不殺程序、不停服務、不改設定。觀察期、校正誤判
Enforce偵測到實際處置：殺整個程序樹 + 停用該工具服務；被開啟的 RDP 改回停用。正式阻斷（需先校正簽章名單）

切換：改 %ProgramData%\Cerberus\cerberus.json 的 Mode，存檔即熱重載。AllowedHosts 內的主機即使在 Enforce 也只告警。

偵測與監看

功能說明開關
遠端工具偵測連線表（TCP/UDP×IPv4/IPv6）+ 程序啟動事件，比對數位簽章 / 版本資訊 / 雜湊，改名也認得。核心
Defender 威脅回報讀 Windows Defender 威脅紀錄，含即時防護自動攔截與各類掃描，發 MalwareDetected 告警。ReportDefenderThreats
異常登入偵測暴力破解（登入失敗達門檻）、遠端桌面登入、帳號鎖定。WatchLogons
RDP 巡檢定時檢查本機遠端桌面是否被偷偷開啟；Enforce 下自動改回停用。GuardRdp

遠端指令（後台按鈕）

以 Agent 主動輪詢取得，只接受下列白名單動作，不能執行任意命令：

按鈕動作影響
快速掃描Defender 快速掃描常見位置掃描期間 CPU/磁碟上升
完整掃描Defender 完整掃描全碟較久、資源占用較高
更新定義更新 Defender 病毒碼無副作用
強化稽核執行強化腳本 只報告現況不改動任何設定
套用強化執行強化腳本 -Apply，實際套用全部 9 項改系統設定，見下節
建議先按「強化稽核」看會動到什麼，確認無虞（尤其 RDP）再按「套用強化」。

「套用強化」逐項說明與影響

以 SYSTEM 權限執行 Harden-Windows.ps1 -Apply，一次套用下列全部項目。每項的現況與結果會回報到「指令紀錄」。

#項目做什麼影響 / 風險
1Defender 即時防護確保即時監控開啟無負面；恢復即時掃描
2防火牆（三設定檔）Domain/Private/Public 全開依賴未開放入站埠的服務可能被擋（一般桌面無感）
3停用遠端桌面fDenyTSConnections=1⚠️ 會切斷/擋掉 RDP 連入。靠 RDP 管這台機器者勿套用此項
4停用 SMBv1關閉高風險舊檔案共享協定僅支援 SMBv1 的舊 NAS/裝置可能無法存取共享。需重開機
5停用 AutoRun/AutoPlay所有磁碟 NoDriveTypeAutoRun=0xFF插入隨身碟/光碟不再自動執行（需手動開啟）；防惡意程式自動執行
6PowerShell 稽核記錄開 ScriptBlock Logging事件日誌量增加；利於事後鑑識
7LSA 保護（RunAsPPL）保護 LSASS 防憑證竊取少數舊驗證模組/第三方掛鉤可能失效。需重開機
8停用 Guest SMB 存取關閉不安全的匿名登入匿名存取的共享會失效，需改用認證
9更新定義 + 快速掃描更新病毒碼並掃描掃描期間資源占用上升；無設定變更
第 4、7 項需重新開機才生效；第 3 項會關閉 RDP。要單獨套用某幾項，請在命令列用 Harden-Windows.ps1 -Apply -Only Defender,Firewall（後台按鈕一律套用全部）。

連線安全

  • HMAC-SHA256 簽章：每個 Agent↔Server 請求含簽章 + 時間戳，防竄改、防重放。
  • TLS + 憑證釘選：Agent 以憑證指紋信任 Server，自簽亦安全、可擋中間人。
  • 每台獨立金鑰：以 HostKeys 每台一把，未註冊主機一律拒絕（見 New-HostKey.ps1）。
  • 指令白名單：Server 只能下達固定動作，即使被攻陷也無法對端點執行任意命令。
